📦 메인 화면 (중앙 카드)
데스크탑 center card의 모바일 번역판. 크기는 화면의 88% width, 세로는 컨텐츠에 맞게.
┌─────────────────────────────────┐
│  muse.log                       │  ← 로고, 좌상단 정렬
│  개발하고 투자하고 살아가는 기록  │  ← 서브타이틀 1줄
│                                 │
│  [GitHub]  [About]  [RSS]       │  ← 아이콘 링크 3개
│ ─────────────────────────────── │
│                                 │
│  (채팅 히스토리 영역)             │  ← 기본엔 비어있음
│                                 │
│ ─────────────────────────────── │
│  🔍 무엇이든 물어보세요...   [↑] │  ← 하단 고정 input
└─────────────────────────────────┘

input 탭 시 키보드 올라오면서 카드가 상단으로 이동 (iOS 네이티브 동작 고려)
채팅 히스토리는 카드 내부 스크롤


🔄 스와이프 탐색 (데스크탑 Edge Hover의 터치 번역)
카드 외부에서 스와이프 제스처로 신경망 노드 전개.
스와이프 좌 → 우  :  IT / 개발 계열 노드 전개
스와이프 우 → 좌  :  아이디어 / 사색 계열 노드 전개
스와이프 아래 → 위:  주식 / 생활 계열 노드 전개
스와이프 위 → 아래:  관계 계열 노드 전개
전개 방식:

스와이프 방향에서 카드를 밀어낼 듯이 노드들이 슬라이드인
카드 자체는 반대 방향으로 살짝 이동 (parallax, 약 30px)
노드 표시 영역: 화면의 40% (카드가 차지하고 남은 공간)

전개된 노드 레이아웃 (세로 리스트):
[ 카테고리명 ]          ← depth 1, 크고 밝게
   ㄴ [ 서브카테고리 ]  ← depth 2, 중간
       ㄴ · 글 제목     ← leaf, 작게. 탭 가능
노드 간 연결선은 유지하되 직선이 아닌 곡선 엣지로 (모바일 가독성)
복귀: 카드 방향으로 스와이프 or 카드 탭 → ambient 상태 복귀

📄 글 상세 — Bottom Sheet
leaf 노드(글) 탭 시 bottom sheet로 등장.
[상태 1 — 절반 열림 (peek)]
  ┌─────────────────────┐
  │ ─── (드래그 핸들)    │
  │ 제목                 │
  │ 카테고리 · 날짜 · n분 │
  │ 첫 두 단락 미리보기   │
  │ [전체 보기 ↓]        │
  └─────────────────────┘

[상태 2 — 풀 스크린 (full drag up)]
  전체 글 내용
  스크롤 가능
  우상단 X 닫기

peek → full: 위로 드래그 or "전체 보기" 탭
닫기: 아래로 드래그 or X 버튼
배경: 블러 처리된 메인 화면 (신경망 ambient 어렴풋이 보임)
bottom sheet 배경: rgba(8, 11, 16, 0.95) + 상단 형광 테두리 1px

📎 전체 프롬프트 통합 시 주의사항 (디자이너에게)

데스크탑과 모바일은 동일한 컨셉의 다른 번역본으로 접근할 것.
신경망 탐색이라는 메타포는 공유하되, 인터랙션 패러다임은 각 디바이스에 네이티브하게.
데스크탑 = 공간을 탐색하는 경험 / 모바일 = 공간을 스쳐지나가는 경험.
